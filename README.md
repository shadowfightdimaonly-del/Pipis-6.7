# Pipis 6.7 Ultra Hammamovich

Экспериментальный проект по созданию собственной AI-модели Pipis на базе открытой модели.

## Цель

Создать Pipis 6.7 как реально дообученную модель, а не просто обёртку над сторонним API.

## Принцип

- открытая базовая модель с подходящей лицензией;
- QLoRA/LoRA для первого этапа обучения;
- собственный качественный датасет Pipis;
- бесплатные GPU-среды для экспериментов, где доступно;
- отдельное тестирование на данных, которые модель не видела при обучении.

## Текущий статус

**Первый QLoRA-эксперимент успешно завершён технически.** В Google Colab на Tesla T4 ноутбук прошёл обучение, сохранил LoRA-адаптер и выполнил генерацию для сравнения Base/Adapter. ZIP адаптера получен пользователем; размер около 38 МБ.

Это пока proof-of-concept, не готовая модель. В трёх ручных тестах адаптер изменил ответы, но показал проблемы: неверно назвал Anthropic как создателя, ошибочно объяснил LoRA и продолжал ответы с повторениями. Первый запуск был ограничен 10 шагами. После него обучающий набор расширен до 121 примера; eval-набор из 8 примеров сохранён отдельно. Датасет прошёл проверку JSONL, на точные дубликаты и пересечение train/eval. Это ещё не доказывает качество ответов: нужен второй запуск и оценка по фиксированной рубрике.
